✨ What Is kiro-cv?

kiro-cv is a portfolio application that opens like a computer terminal. Instead of scrolling a static web page, your visitor sees a familiar command-line window with a blinking cursor, a prompt, and a welcome message. Everything they want to know about you is one short command away.

If the visitor already knows what they are looking for, they type a slash command such as the one for your work history and the answer appears instantly, formatted neatly inside the terminal window. If they would rather just talk, they type an ordinary sentence and an AI chat replies in your voice, using your real background as the source of truth.

The effect is memorable. A recruiter who has opened fifty identical portfolio pages in one afternoon will remember the one that answered their questions like a program. That is the whole idea behind kiro-cv: keep the information professional and easy to find, then deliver it in a way nobody expects.

💬 Two Ways to Explore

Everything in kiro-cv happens through the small input line at the bottom of the terminal window. There are exactly two kinds of input, and the application decides which one you meant based on the very first character you type.

Slash commands — instant, structured answers

Starting a line with a forward slash tells the application exactly which section of your portfolio to display. The reply arrives immediately with no waiting, laid out in clean columns and rows. Typical commands cover your work history, your technical skills, your certifications, your education, your contact details, and a short introduction. A help command lists everything available, so a first-time visitor is never lost.

Plain text — a conversation in your voice

If the visitor types an ordinary sentence instead, the AI chat takes over. It answers as you, drawing on the same experience, skills, and certification details stored in your portfolio files. Someone can ask a relaxed question about how you approach a difficult deadline, and get a reply written in the first person that still matches the facts on record.

A terminal that behaves like a terminal

The window keeps a scrollable history of everything typed and every reply, so a visitor can look back at earlier answers. Long replies wrap neatly instead of running off the edge. The whole thing feels like a real command-line tool rather than a web page pretending to be one, which is exactly the point.

🛠️ If Something Goes Wrong

The window opens and closes right away. This usually means the application was started from inside the compressed file instead of the extracted folder. Close everything, go back to the extracted folder, and double-click the application file there.

Windows shows a blue permission message. This is the standard warning for programs downloaded from the internet. Click the option that allows the program to run. If you would rather check first, open the file properties and confirm the publisher matches the project page.

Typing a slash command does nothing. Make sure the very first character is a forward slash with no space in front of it. Then press Enter. A help command will show the full list of commands if you are unsure of the exact wording.

The chat replies are slow or missing. The conversational part of the application needs an internet connection. Check that you are online, then try the question again.

The text looks cramped or cut off. Widen the terminal window by dragging its edge, or reduce the text size in the window settings so more characters fit on each line.

🙋 Common Questions

Do I need to know how to code to use it? No. You open the folder, double-click the application, and type commands the same way you would type a message. Nothing needs to be configured by hand.

Can I change the content to my own details? Yes. The experience, skills, and certification entries live in ordinary text files inside the project folder. Swapping the text for your own information is enough to make the portfolio yours.

Will visitors see my files or my computer? No. Visitors only see the terminal window with the answers you have written. Nothing else on your machine is exposed.

Does the AI make up facts about me? The chat is instructed to answer from the details stored in the portfolio files and to stay in character as you. Keeping those files accurate keeps the answers accurate.
